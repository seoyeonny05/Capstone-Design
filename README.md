# 캡스톤디자인 작품 개발계획서

## 1. 작품 개요

### 1.1 작품명

**FindBox - AI 기반 스마트 분실물 관리 시스템**

### 1.2 작품 분야

IoT · 인공지능(AI) · 컴퓨터비전 · 웹 서비스

### 1.3 작품 개요

FindBox는 학교 내 분실물 관리를 효율적으로 지원하기 위한 스마트 분실물 관리 시스템이다.

학생은 웹페이지를 통해 분실물 정보를 등록할 수 있으며, 습득자는 스마트 보관함에 물건을 넣기만 하면 센서와 카메라가 자동으로 물건을 인식하여 습득물 게시글을 생성한다.

시스템은 등록된 분실물 정보와 새롭게 등록된 습득물 정보를 비교하여 AI 기반 매칭률을 계산하고, 사용자가 분실물을 더욱 빠르게 찾을 수 있도록 지원한다.

### 1.4 주요 기능

- 분실물 등록 기능
- 스마트 보관함 기반 습득물 자동 등록
- 카메라 자동 촬영 기능
- AI 기반 분실물·습득물 매칭
- 관리자 관리 기능
- 웹 기반 조회 서비스

# 2. 개발 배경 및 필요성

## 2.1 개발 배경

학교에서는 이어폰, 지갑, 학생증 등 다양한 물건이 자주 분실된다.

현재 분실물은 학생복지과에서 수동으로 관리되는 경우가 많아 분실자가 직접 방문하여 확인해야 하며, 습득자와 분실자가 서로를 찾기 어려운 문제가 있다.

또한 분실물이 장기간 보관되거나 반환되지 못하는 사례가 발생하고 있어 보다 효율적인 관리 시스템이 필요하다.

## 2.2 개발 필요성

1. 분실물 관리 자동화
2. 분실물 반환률 향상
3. 학생 편의성 증대
4. 관리자의 업무 감소
5. AI 및 IoT 융합 기술 적용 경험 확보
